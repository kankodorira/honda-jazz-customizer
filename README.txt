HONDA JAZZ — Visual Prototype 01 / 0.3.0

JAZZのシルエットと、タイヤ外径変更による雰囲気を確認するための自作3Dプロトタイプです。
ドラッグで回転、前後タイヤの外径スライダーで車体の姿勢を変更できます。
タイヤ外径を変えると、前後フェンダーは厚みと幅を保ったまま自然な隙間を維持します。
ハンドルはノーマルに加え、ユーザー提供の形状図を基にした17種類から選べます。
タンクはノーマルに加え、横伸びを補正した参考図を基にした10種類から選べます。
「外観を元に戻す」でハンドルとタンクをノーマル形状へ戻せます。
3Dが使えない環境では、同じモデルから作成した静止画を表示します。
WebGL対応ブラウザでの利用を想定しています。実車への装着可否やサスペンションの物理挙動は判定しません。

ホイールベース1,325 mm、前後リム16/12 inchはHondaの公表値を参照しています。
タイヤ外径534 mmの基準値やその他の形状は近似です。精密CADではありません。
参考: https://global.honda/jp/news/1992/2920220j.html

Hondaの公式サービスではありません。モデルはこのプロトタイプ用に作成されたものです。
参照写真は含まれていません。解析・広告・アカウント登録・データ収集機能はありません。
